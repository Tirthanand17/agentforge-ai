# Market Research — Full-Stack Agentic AI Portfolio

Research date: 2026-10-04

## Repeated requirements found in current Upwork AI SaaS jobs

Across current full-stack AI, RAG, and agent-development listings, the recurring requirements are:

- React / Next.js / TypeScript
- Python / FastAPI
- LLM integration
- RAG pipelines
- vector databases / embeddings
- AI agents and tool calling
- PostgreSQL / Supabase
- authentication and multi-tenancy
- REST APIs / webhooks / streaming
- Docker / cloud deployment
- evaluation, guardrails, latency and cost optimization
- MCP, LangGraph, n8n, or other workflow integrations as differentiators
